# Fictional sample resumes

To try the application locally, create one or more short fictional resumes in a document editor and export them as text-based PDFs. Use invented names and generic details, for example:

- `sample_data_analyst.pdf`: fictional candidate with Python, SQL, pandas, and Power BI experience.
- `sample_data_general.pdf`: fictional candidate with project coordination and Excel experience.

Upload these PDFs alongside a job description that names some of those skills. You can also create an empty PDF or upload a non-PDF renamed with a `.pdf` extension to check that invalid files are reported without stopping other resumes.

Do not put real candidate resumes, personal information, or private employment data in this repository. This folder intentionally contains instructions only; generated local test files should not be committed.
